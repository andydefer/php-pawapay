# InitiateDepositBuilder - Référence Technique

## Description

Construit un objet `InitiateDepositVO` décrivant une demande d'initiation de dépôt Mobile Money auprès de Pawapay.

## Hiérarchie / Implémentations

```
InitiateDepositBuilder (final class)
```

Aucune interface implémentée, aucune classe parente. Classe autonome.

## Rôle principal

`InitiateDepositBuilder` offre une API fluide pour assembler progressivement les données d'un dépôt Mobile Money avant de produire un `InitiateDepositVO` prêt à être envoyé au service Pawapay.

Il encapsule :

1. la génération automatique d'un `depositId` UUID v4,
2. les valeurs par défaut (`PayerType::MMO`, `Provider::MTN_MOMO_ZMB`, `Currency::ZMW`),
3. la construction de la hiérarchie `PayerVO` → `AccountDetailsVO`,
4. la conversion des types primitifs (string, float) en Value Objects validés.

Il est destiné aux cas où l'on souhaite initier un dépôt sans passer par un `Record` (approche bas niveau).

## Installation

Aucune installation spécifique. La classe est fournie par le package `andydefer/php-pawapay`.

```bash
composer require andydefer/php-pawapay
```

## API / Méthodes publiques

### `__construct()`

Initialise le builder avec des valeurs par défaut.

**Valeurs par défaut :**
- `$depositId` = UUID v4 auto-généré
- `$payerType` = `PayerType::MMO`
- `$provider` = `Provider::MTN_MOMO_ZMB`
- `$currency` = `Currency::ZMW`

**Exemple :**

```php
$builder = new InitiateDepositBuilder();
```

---

### `create(): self`

Factory statique. Équivalent au constructeur.

**Retourne :** `self` — Nouvelle instance.

**Exemple :**

```php
$builder = InitiateDepositBuilder::create();
```

---

### `withDepositId(string $depositId): self`

Définit manuellement l'identifiant UUID du dépôt.

| Paramètre | Type | Description |
|-----------|------|-------------|
| `$depositId` | `string` | UUID v4 valide |

**Retourne :** `self`

**Exceptions :** `InvalidArgumentException` si l'UUID est invalide (levée par `UuidVO`).

**Exemple :**

```php
$builder->withDepositId('f4401bd2-1568-4140-bf2d-eb77d2b2b639');
```

---

### `withAutoGeneratedDepositId(): self`

Régénère un nouvel UUID v4 pour le dépôt.

**Retourne :** `self`

**Exemple :**

```php
$builder->withAutoGeneratedDepositId();
```

**Note :** Un UUID est déjà généré dans le constructeur. Utile uniquement si `withDepositId()` a été appelé et que l'on souhaite revenir à un ID auto-généré.

---

### `withPhoneNumber(string $phoneNumber): self`

Définit le numéro de téléphone du payeur.

| Paramètre | Type | Description |
|-----------|------|-------------|
| `$phoneNumber` | `string` | Numéro au format E.164 sans `+` (ex: `260763456789`) |

**Retourne :** `self`

**Exceptions :** `InvalidArgumentException` si le format est invalide.

**Exemple :**

```php
$builder->withPhoneNumber('260763456789');
```

---

### `withProvider(Provider $provider): self`

Définit le fournisseur Mobile Money.

| Paramètre | Type | Description |
|-----------|------|-------------|
| `$provider` | `Provider` | Enum du fournisseur (`MTN_MOMO_ZMB`, `VODACOM_MPESA_COD`, etc.) |

**Retourne :** `self`

**Exemple :**

```php
$builder->withProvider(Provider::VODACOM_MPESA_COD);
```

---

### `withAmount(float $amount): self`

Définit le montant du dépôt.

| Paramètre | Type | Description |
|-----------|------|-------------|
| `$amount` | `float` | Montant positif, 2 décimales max |

**Retourne :** `self`

**Exceptions :** `InvalidArgumentException` si le montant est négatif, nul ou non fini.

**Exemple :**

```php
$builder->withAmount(15.00);
```

---

### `withCurrency(Currency $currency): self`

Définit la devise du dépôt.

| Paramètre | Type | Description |
|-----------|------|-------------|
| `$currency` | `Currency` | Enum de devise (`ZMW`, `USD`, `KES`, etc.) |

**Retourne :** `self`

**Exemple :**

```php
$builder->withCurrency(Currency::USD);
```

---

### `withPreAuthorisationCode(?string $code): self`

Définit un code de pré-autorisation optionnel.

| Paramètre | Type | Description |
|-----------|------|-------------|
| `$code` | `?string` | Code de pré-autorisation, ou `null` pour désactiver |

**Retourne :** `self`

**Exemple :**

```php
$builder->withPreAuthorisationCode('PRE-AUTH-123');
```

---

### `withClientReferenceId(?string $referenceId): self`

Définit une référence client optionnelle (4 à 64 caractères).

| Paramètre | Type | Description |
|-----------|------|-------------|
| `$referenceId` | `?string` | Référence, ou `null` pour désactiver |

**Retourne :** `self`

**Exceptions :** `InvalidArgumentException` si la référence viole les contraintes de `ClientReferenceIdVO` (longueur, format).

**Exemple :**

```php
$builder->withClientReferenceId('INV-123456');
```

---

### `withCustomerMessage(?string $message): self`

Définit un message affiché au client (4 à 22 caractères).

| Paramètre | Type | Description |
|-----------|------|-------------|
| `$message` | `?string` | Message court, ou `null` pour désactiver |

**Retourne :** `self`

**Exceptions :** `InvalidArgumentException` si le message viole les contraintes de `CustomerMessageVO`.

**Exemple :**

```php
$builder->withCustomerMessage('Payment order 123');
```

---

### `withMetadata(array $metadata): self`

Définit les metadata du dépôt en une seule fois.

| Paramètre | Type | Description |
|-----------|------|-------------|
| `$metadata` | `array<string, scalar>` | Tableau associatif clé → valeur |

**Retourne :** `self`

**Exceptions :** `InvalidArgumentException` si plus de 10 champs ou valeur non scalaire.

**Exemple :**

```php
$builder->withMetadata([
    'orderId' => 'ORD-123',
    'customerId' => 'CUST-456',
]);
```

---

### `withMetadataKey(string $key, string $value): self`

Ajoute ou remplace une clé de metadata.

| Paramètre | Type | Description |
|-----------|------|-------------|
| `$key` | `string` | Clé de metadata |
| `$value` | `string` | Valeur scalaire |

**Retourne :** `self`

**Exemple :**

```php
$builder->withMetadataKey('orderId', 'ORD-123');
```

**Note :** Appelable plusieurs fois pour accumuler les clés.

---

### `build(): InitiateDepositVO`

Assemble la hiérarchie complète (`PayerVO` → `AccountDetailsVO`) et retourne un `InitiateDepositVO` prêt à être envoyé.

**Retourne :** `InitiateDepositVO` — Value Object de la demande de dépôt.

**Exceptions :**
- `Error` (PHP) — si `$phoneNumber` ou `$amount` n'ont pas été définis (propriétés typées non initialisées).
- `InvalidArgumentException` — si une valeur viole les contraintes d'un Value Object.

**Exemple :**

```php
$vo = $builder->build();
```

---

## Cas d'utilisation

### Cas 1 : Dépôt minimal

Initiation d'un dépôt avec les paramètres obligatoires uniquement.

```php
<?php

declare(strict_types=1);

use AndyDefer\PhpPawapay\Builders\InitiateDepositBuilder;

$deposit = InitiateDepositBuilder::create()
    ->withPhoneNumber('260763456789')
    ->withAmount(15.00)
    ->build();
```

### Cas 2 : Dépôt complet avec metadata

Ajout de référence client, message et metadata pour la réconciliation.

```php
<?php

declare(strict_types=1);

use AndyDefer\PhpPawapay\Builders\InitiateDepositBuilder;
use AndyDefer\PhpPawapay\Enums\Currency;
use AndyDefer\PhpPawapay\Enums\Provider;

$deposit = InitiateDepositBuilder::create()
    ->withAutoGeneratedDepositId()
    ->withPhoneNumber('260763456789')
    ->withProvider(Provider::MTN_MOMO_ZMB)
    ->withAmount(15.00)
    ->withCurrency(Currency::ZMW)
    ->withClientReferenceId('INV-123456')
    ->withCustomerMessage('Payment order 123')
    ->withMetadataKey('orderId', 'ORD-123')
    ->withMetadataKey('customerId', 'CUST-456')
    ->build();
```

### Cas 3 : Intégration dans une Action métier

Construction du VO dans un service avant envoi via `PawapayService`.

```php
<?php

declare(strict_types=1);

namespace App\Actions;

use AndyDefer\PhpPawapay\Builders\InitiateDepositBuilder;
use AndyDefer\PhpPawapay\Enums\Currency;
use AndyDefer\PhpPawapay\Enums\Provider;
use App\Models\Order;

final class BuildDepositAction
{
    public function handle(Order $order): \AndyDefer\PhpPawapay\ValueObjects\InitiateDepositVO
    {
        return InitiateDepositBuilder::create()
            ->withPhoneNumber($order->customer_phone)
            ->withProvider(Provider::from($order->provider_code))
            ->withAmount($order->total)
            ->withCurrency(Currency::from($order->currency))
            ->withClientReferenceId($order->reference)
            ->withMetadataKey('orderId', (string) $order->id)
            ->build();
    }
}
```

## Flux d'exécution

```
InitiateDepositBuilder::create()
    │
    ├── __construct
    │       ├── depositId = Uuid v4 auto
    │       ├── payerType = PayerType::MMO
    │       ├── provider  = Provider::MTN_MOMO_ZMB
    │       └── currency  = Currency::ZMW
    │
    ├── withPhoneNumber / withAmount / withProvider / ...   (chaînage)
    │
    └── build()
            │
            ├── new AccountDetailsVO(phoneNumber, provider)
            │
            ├── new PayerVO(type, accountDetails)
            │
            └── new InitiateDepositVO(
                    depositId,
                    payer,
                    amount,
                    currency,
                    preAuthorisationCode,
                    clientReferenceId,
                    customerMessage,
                    metadata
                )
```

## Gestion des erreurs

| Situation | Exception | Message |
|-----------|-----------|---------|
| Téléphone non défini | `Error` (PHP) | `Typed property ... must not be accessed before initialization` |
| Montant non défini | `Error` (PHP) | Idem |
| UUID invalide | `InvalidArgumentException` | `Invalid UUID: xxx` |
| Téléphone invalide | `InvalidArgumentException` | `Invalid phone number: xxx` |
| Montant négatif ou nul | `InvalidArgumentException` | `Amount must be positive: xxx` |
| Référence client invalide | `InvalidArgumentException` | Message dépendant de `ClientReferenceIdVO` |
| Message client invalide | `InvalidArgumentException` | Message dépendant de `CustomerMessageVO` |
| Metadata > 10 champs | `InvalidArgumentException` | `Metadata cannot exceed 10 fields. Got X fields.` |
| Valeur de metadata non scalaire | `InvalidArgumentException` | `Metadata value for key "xxx" must be a scalar.` |

## Intégration

| Composant | Rôle |
|-----------|------|
| `InitiateDepositVO` | Value Object produit par `build()` |
| `PayerVO` | Value Object du payeur construit en interne |
| `AccountDetailsVO` | Value Object des détails de compte construit en interne |
| `AmountVO` | Value Object du montant |
| `PhoneNumberVO` | Value Object du numéro de téléphone |
| `MetadataVO` | Value Object des metadata |
| `ClientReferenceIdVO` | Value Object de la référence client |
| `CustomerMessageVO` | Value Object du message client |
| `Provider`, `Currency`, `PayerType` | Enums utilisés pour les choix fixes |

Le builder **ne fait aucun appel réseau**. Il produit un `InitiateDepositVO` qui doit être passé à `PawapayService::initiateDeposit()` ou à `PawapayClient::initiateDeposit()` selon la couche visée.

## Performance

- Aucun appel réseau, aucune I/O.
- Construction en O(1) — pas de boucle.
- Chaque `withXxx()` réassigne une propriété — coût négligeable.
- La validation se produit à la construction des Value Objects, pas à `build()`.

# CreatePaymentPageBuilder - Référence Technique

## Description

Construit et exécute une requête de création de page de paiement hébergée par Pawapay.

## Hiérarchie / Implémentations

```
CreatePaymentPageBuilder (final class)
```

Aucune interface implémentée, aucune classe parente. Classe autonome.

## Rôle principal

`CreatePaymentPageBuilder` offre une API fluide pour générer une page de paiement Pawapay hébergée, vers laquelle l'utilisateur final sera redirigé pour saisir ses informations Mobile Money.

Il encapsule :

1. la configuration du client HTTP (token, URL de base),
2. les paramètres obligatoires (montant, devise, téléphone, pays, URL de retour),
3. les paramètres optionnels (message client, raison, metadata, langue),
4. la génération automatique d'un `depositId` UUID v4,
5. la construction du `PaymentPageStruct` et l'appel réseau.

Il est destiné aux cas où l'on souhaite déléguer l'UI de saisie Mobile Money à Pawapay plutôt que de la construire soi-même.

## Installation

Aucune installation spécifique. La classe est fournie par le package `andydefer/php-pawapay`.

```bash
composer require andydefer/php-pawapay
```

## API / Méthodes publiques

### `__construct(string $apiToken)`

Initialise le builder avec un token d'API Pawapay.

| Paramètre | Type | Description |
|-----------|------|-------------|
| `$apiToken` | `string` | Token d'authentification Bearer fourni par Pawapay |

**Retourne :** Aucun (constructeur).

**Valeurs par défaut :**
- `$baseUrl` = `PawaPayBaseUrl::SANDBOX`
- `$depositId` = UUID v4 auto-généré
- `$language` = `Language::EN`
- `$country` = `Country::ZMB`
- `$currency` = `Currency::ZMW`

**Exemple :**

```php
$builder = new CreatePaymentPageBuilder('votre-token-api');
```

---

### `create(string $apiToken): self`

Factory statique. Équivalent au constructeur.

| Paramètre | Type | Description |
|-----------|------|-------------|
| `$apiToken` | `string` | Token d'authentification Bearer |

**Retourne :** `self` — Nouvelle instance.

**Exemple :**

```php
$builder = CreatePaymentPageBuilder::create('votre-token-api');
```

---

### `withBaseUrl(PawaPayBaseUrl $baseUrl): self`

Définit l'environnement Pawapay à utiliser.

| Paramètre | Type | Description |
|-----------|------|-------------|
| `$baseUrl` | `PawaPayBaseUrl` | Enum de l'URL de base (`SANDBOX` ou `PRODUCTION`) |

**Retourne :** `self` — Instance courante pour chaînage.

**Exemple :**

```php
$builder->withBaseUrl(PawaPayBaseUrl::PRODUCTION);
```

---

### `withDepositId(string $depositId): self`

Définit manuellement l'identifiant UUID du dépôt.

| Paramètre | Type | Description |
|-----------|------|-------------|
| `$depositId` | `string` | UUID v4 valide |

**Retourne :** `self`

**Exceptions :** `InvalidArgumentException` si l'UUID est invalide (levée par `UuidVO`).

**Exemple :**

```php
$builder->withDepositId('f4401bd2-1568-4140-bf2d-eb77d2b2b639');
```

---

### `withAutoGeneratedDepositId(): self`

Régénère un nouvel UUID v4 pour le dépôt.

**Retourne :** `self`

**Exemple :**

```php
$builder->withAutoGeneratedDepositId();
```

**Note :** Un UUID est déjà généré dans le constructeur. Cette méthode est utile uniquement si `withDepositId()` a été appelé précédemment et que l'on souhaite revenir à un ID auto-généré.

---

### `withPhoneNumber(string $phoneNumber): self`

Définit le numéro de téléphone du payeur.

| Paramètre | Type | Description |
|-----------|------|-------------|
| `$phoneNumber` | `string` | Numéro au format E.164 sans `+` (ex: `260763456789`) |

**Retourne :** `self`

**Exceptions :** `InvalidArgumentException` si le format est invalide.

**Exemple :**

```php
$builder->withPhoneNumber('260763456789');
```

---

### `withAmount(AmountVO|float $amount): self`

Définit le montant du paiement.

| Paramètre | Type | Description |
|-----------|------|-------------|
| `$amount` | `AmountVO\|float` | Montant positif, 2 décimales max |

**Retourne :** `self`

**Exceptions :** `InvalidArgumentException` si le montant est négatif, nul ou non fini.

**Exemple :**

```php
$builder->withAmount(24.60);
// ou
$builder->withAmount(AmountVO::from(24.60));
```

---

### `withCurrency(Currency $currency): self`

Définit la devise du paiement.

| Paramètre | Type | Description |
|-----------|------|-------------|
| `$currency` | `Currency` | Enum de devise (`ZMW`, `USD`, `KES`, etc.) |

**Retourne :** `self`

**Exemple :**

```php
$builder->withCurrency(Currency::USD);
```

---

### `withReturnUrl(string $returnUrl): self`

Définit l'URL de retour après paiement.

| Paramètre | Type | Description |
|-----------|------|-------------|
| `$returnUrl` | `string` | URL absolue valide |

**Retourne :** `self`

**Exceptions :** `InvalidArgumentException` si l'URL est invalide (levée par `UrlVO`).

**Exemple :**

```php
$builder->withReturnUrl('https://example.com/success');
```

---

### `withLanguage(Language $language): self`

Définit la langue de la page de paiement.

| Paramètre | Type | Description |
|-----------|------|-------------|
| `$language` | `Language` | Enum de langue (`EN` ou `FR`) |

**Retourne :** `self`

**Exemple :**

```php
$builder->withLanguage(Language::FR);
```

---

### `withCountry(Country $country): self`

Définit le pays du payeur.

| Paramètre | Type | Description |
|-----------|------|-------------|
| `$country` | `Country` | Enum de pays (`ZMB`, `COD`, `KEN`, etc.) |

**Retourne :** `self`

**Exemple :**

```php
$builder->withCountry(Country::COD);
```

---

### `withCustomerMessage(?string $message): self`

Définit un message affiché au client (4 à 22 caractères).

| Paramètre | Type | Description |
|-----------|------|-------------|
| `$message` | `?string` | Message court, ou `null` pour désactiver |

**Retourne :** `self`

**Exceptions :** `InvalidArgumentException` si le message fait moins de 4 ou plus de 22 caractères.

**Exemple :**

```php
$builder->withCustomerMessage('Paiement commande');
```

---

### `withReason(?string $reason): self`

Définit la raison du paiement (4 à 22 caractères).

| Paramètre | Type | Description |
|-----------|------|-------------|
| `$reason` | `?string` | Raison courte, ou `null` pour désactiver |

**Retourne :** `self`

**Exceptions :** `InvalidArgumentException` si la raison fait moins de 4 ou plus de 22 caractères.

**Exemple :**

```php
$builder->withReason('Commande 12345');
```

---

### `withMetadata(array $metadata): self`

Définit les metadata du paiement en une seule fois.

| Paramètre | Type | Description |
|-----------|------|-------------|
| `$metadata` | `array<string, scalar>` | Tableau associatif clé → valeur |

**Retourne :** `self`

**Exceptions :** `InvalidArgumentException` si plus de 10 champs ou valeur non scalaire.

**Exemple :**

```php
$builder->withMetadata([
    'orderId' => 'ORD-123',
    'customerId' => 'CUST-456',
]);
```

---

### `withMetadataKey(string $key, string $value): self`

Ajoute ou remplace une clé de metadata.

| Paramètre | Type | Description |
|-----------|------|-------------|
| `$key` | `string` | Clé de metadata |
| `$value` | `string` | Valeur scalaire |

**Retourne :** `self`

**Exemple :**

```php
$builder->withMetadataKey('orderId', 'ORD-123');
```

**Note :** Appelable plusieurs fois pour accumuler les clés.

---

### `build(): PawapayClient`

Construit le client HTTP Pawapay à partir de la configuration courante.

**Retourne :** `PawapayClient` — Client bas niveau prêt à l'emploi.

**Exemple :**

```php
$client = $builder->build();
```

---

### `execute(): CreatePaymentPageResponse`

Construit le `PaymentPageStruct` puis exécute l'appel HTTP `POST /v2/paymentpage`.

**Retourne :** `CreatePaymentPageResponse` — Réponse typée contenant l'URL de redirection.

**Exceptions :**
- `Error` (PHP) — si une propriété requise n'a pas été initialisée (ex: `$phoneNumber`, `$amount`, `$returnUrl`).
- Exception réseau de Guzzle — si la requête échoue.

**Exemple :**

```php
$response = $builder->execute();
```

---

## Cas d'utilisation

### Cas 1 : Page de paiement minimale

Génération d'une page avec les paramètres obligatoires uniquement.

```php
<?php

declare(strict_types=1);

use AndyDefer\PhpPawapay\Builders\CreatePaymentPageBuilder;

$response = CreatePaymentPageBuilder::create('votre-token')
    ->withPhoneNumber('260763456789')
    ->withAmount(24.60)
    ->withReturnUrl('https://example.com/success')
    ->execute();

if ($response->getRedirectUrl() !== null) {
    header('Location: ' . $response->getRedirectUrlAsString());
    exit;
}
```

### Cas 2 : Page de paiement complète avec metadata

Ajout de metadata pour la réconciliation côté backoffice.

```php
<?php

declare(strict_types=1);

use AndyDefer\PhpPawapay\Builders\CreatePaymentPageBuilder;
use AndyDefer\PhpPawapay\Enums\Country;
use AndyDefer\PhpPawapay\Enums\Currency;
use AndyDefer\PhpPawapay\Enums\Language;
use AndyDefer\PhpPawapay\Enums\PawaPayBaseUrl;

$response = CreatePaymentPageBuilder::create($token)
    ->withBaseUrl(PawaPayBaseUrl::PRODUCTION)
    ->withAutoGeneratedDepositId()
    ->withPhoneNumber('243827833329')
    ->withAmount(24.60)
    ->withCurrency(Currency::USD)
    ->withReturnUrl('https://example.com/success')
    ->withLanguage(Language::FR)
    ->withCountry(Country::COD)
    ->withCustomerMessage('Paiement commande')
    ->withReason('Commande 12345')
    ->withMetadataKey('orderId', 'ORD-123')
    ->withMetadataKey('customerId', 'CUST-456')
    ->execute();

if ($response->getRedirectUrl() !== null) {
    return redirect()->away($response->getRedirectUrlAsString());
}
```

### Cas 3 : Intégration dans un contrôleur Laravel

```php
<?php

declare(strict_types=1);

namespace App\Http\Controllers;

use AndyDefer\PhpPawapay\Builders\CreatePaymentPageBuilder;
use AndyDefer\PhpPawapay\Enums\PawaPayBaseUrl;
use Illuminate\Http\RedirectResponse;

final class PaymentController
{
    public function checkout(Order $order): RedirectResponse
    {
        $response = CreatePaymentPageBuilder::create(config('pawapay.api_token'))
            ->withBaseUrl(PawaPayBaseUrl::PRODUCTION)
            ->withPhoneNumber($order->customer_phone)
            ->withAmount($order->total)
            ->withCurrency($order->currency)
            ->withReturnUrl(route('checkout.success', $order))
            ->withMetadataKey('orderId', (string) $order->id)
            ->execute();

        return redirect()->away($response->getRedirectUrlAsString());
    }
}
```

## Flux d'exécution

```
CreatePaymentPageBuilder::create($token)
    │
    ├── __construct
    │       ├── depositId = Uuid v4 auto
    │       ├── language  = EN
    │       ├── country   = ZMB
    │       └── currency  = ZMW
    │
    ├── withBaseUrl / withPhoneNumber / withAmount / ...    (chaînage)
    │
    └── execute()
            │
            ├── build() → new PawapayClient($token, $baseUrl)
            │
            ├── new AmountDetailsGraph(amount, currency)
            │
            ├── new PaymentPageStruct(
            │       depositId, returnUrl, amountDetails,
            │       phoneNumber, language, country,
            │       customerMessage, reason, metadata
            │   )
            │
            ├── $client->createPaymentPage($struct)
            │       │
            │       ├── new CreatePaymentPageRequest($struct, $baseUrl)
            │       ├── headers: Authorization, Content-Type, Accept
            │       ├── options: timeout=30, connectTimeout=10, httpErrors=false
            │       │
            │       └── ClientService::post(...)
            │
            └── CreatePaymentPageResponse
```

## Gestion des erreurs

| Situation | Exception | Message |
|-----------|-----------|---------|
| Téléphone non défini | `Error` (PHP) | `Typed property ... must not be accessed before initialization` |
| Montant non défini | `Error` (PHP) | Idem |
| URL de retour non définie | `Error` (PHP) | Idem |
| UUID invalide | `InvalidArgumentException` | `Invalid UUID: xxx` |
| URL de retour invalide | `InvalidArgumentException` | `Invalid URL: xxx` |
| Montant négatif | `InvalidArgumentException` | `Amount must be positive: xxx` |
| Message client trop court | `InvalidArgumentException` | `Customer message must be at least 4 characters, X given.` |
| Message client trop long | `InvalidArgumentException` | `Customer message must not exceed 22 characters, X given.` |
| Metadata > 10 champs | `InvalidArgumentException` | `Metadata cannot exceed 10 fields. Got X fields.` |
| Erreur API Pawapay | Pas d'exception | `$response->hasFailureReason()` retourne `true` |
| Erreur réseau | `GuzzleException` | Message dépendant de Guzzle |

## Intégration

| Composant | Rôle |
|-----------|------|
| `PawapayClient` | Client HTTP bas niveau construit via `build()` |
| `PawaPayBaseUrl` | Enum de l'URL de base (sandbox / production) |
| `PaymentPageStruct` | Struct envoyé dans le corps de la requête |
| `AmountDetailsGraph` | Graph imbriqué (montant + devise) |
| `CreatePaymentPageRequest` | Requête HTTP générée en interne par le client |
| `CreatePaymentPageResponse` | Réponse typée retournée par `execute()` |

Le builder est **synchrone** et **bloquant**. La page est générée côté Pawapay, l'utilisateur est redirigé via `redirectUrl`.

## Performance

- **Une seule requête HTTP** par appel à `execute()`.
- `build()` instancie un nouveau `PawapayClient` à chaque appel.
- Validation des Value Objects à la construction — coût négligeable.
- Le coût dominant est le round-trip réseau vers Pawapay (typiquement 150–600 ms).

## Exemple complet

```php
<?php

declare(strict_types=1);

use AndyDefer\PhpPawapay\Builders\CreatePaymentPageBuilder;
use AndyDefer\PhpPawapay\Enums\Country;
use AndyDefer\PhpPawapay\Enums\Currency;
use AndyDefer\PhpPawapay\Enums\Language;
use AndyDefer\PhpPawapay\Enums\PawaPayBaseUrl;

$response = CreatePaymentPageBuilder::create('eyJraWQiOiIx...')
    ->withBaseUrl(PawaPayBaseUrl::SANDBOX)
    ->withAutoGeneratedDepositId()
    ->withPhoneNumber('243827833329')
    ->withAmount(24.60)
    ->withCurrency(Currency::USD)
    ->withReturnUrl('https://example.com/success')
    ->withLanguage(Language::FR)
    ->withCountry(Country::COD)
    ->withCustomerMessage('Paiement commande')
    ->withReason('Commande 12345')
    ->withMetadataKey('orderId', 'ORD-123')
    ->withMetadataKey('customerId', 'CUST-456')
    ->execute();

if ($response->hasFailureReason()) {
    $reason = $response->getFailureReason();
    throw new RuntimeException("Pawapay error: {$reason->failureCode->value} - {$reason->failureMessage}");
}

header('Location: ' . $response->getRedirectUrlAsString());
exit;
```
